# adrianov/abcop

Homebrew tap for [abcop](https://github.com/adrianov/abcop) — ABC complexity gate for AI-written code.

## Install

```sh
brew install adrianov/abcop/abcop
```

Or:

```sh
brew tap adrianov/abcop
brew install abcop
```
